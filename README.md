A deterministic program that writes one robot-vacuum excuse of at most 120
characters to `/output/entry.txt`. Uses Node 22 and only the standard library.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Without `MAKEFUN_OUTPUT_DIR`, the output directory defaults to `/output`.
The program validates the single line before writing it. Candidate comparisons
and the final refinement are recorded in `CANDIDATES.md`.
